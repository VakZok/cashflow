# Self-hosted on the user's own Linux host, no app login

The app runs on a Linux host of the user's choosing with a SQLite database, listening on localhost only; how the user reaches it (VPN, reverse proxy on the LAN, SSH tunnel) is the user's choice, and that access path is the only access control, so the app has no login. We chose this over browser-only storage (data trapped on one device) and cloud backends (hosting cost, third-party custody of financial data). iCloud sync of the live database was rejected because syncing SQLite files corrupts them. Consequences: the app must never be exposed publicly, and the database must be backed up (a nightly, integrity-checked, dated local copy, optionally pushed with `rclone copy` to a remote the user configures; where that remote lives and what happens there is the user's concern, not this project's).
